# Codemap: Entry Points

All entry points are in `src/`. They are invoked via pnpm scripts defined in `package.json`. Each script uses `dotenv-cli` to inject `.env` before execution and `tsx` to run TypeScript directly.

---

## Stage 1: Crawl

### `src/crawl.ts`

**Command**: `pnpm crawl`

**Flags**:

| Flag | Example | Effect |
|------|---------|--------|
| `--site=KEY` | `--site=obscura` | Crawl a single site by key. Comma-separated for multiple. |
| `--site=KEY,KEY2` | `--site=obscura,llud` | Crawl multiple sites in sequence. |
| `--all` | — | Crawl all active (non-disabled) platforms. |
| `--type=TYPE` | `--type=cafe24` | Crawl all platforms of a given type. |
| `--list` | — | Print all registered platforms and exit. No crawling. |
| `--probe=KEY` | `--probe=obscura` | Load the site page and check accessibility. No product collection. |
| `--dry-run` | `--dry-run --site=KEY` | Run category discovery only. No product pages fetched. |

**Reads**: `src/configs/platforms.ts` (SiteConfig registry).

**Writes**: `data/{key}-products.json` — one file per site key. Overwrites on each run.

**Supabase**: None. This script does not touch Supabase.

**Notes**: For Cafe24 sites, launches a Playwright Chromium browser (headless). For Shopify sites, uses native `fetch`. Browser is shared across all Cafe24 crawls in a single run.

## Stage 2: Import

### `src/import-products.ts`

**Command**: `pnpm import:products`

**Flags**:

| Flag | Example | Effect |
|------|---------|--------|
| `--site=KEY` | `--site=obscura` | Import only the JSON file for the given site key. |
| (none) | — | Import all `data/*-products.json` files found on disk. |

**Reads**: `data/{key}-products.json` (written by `crawl.ts`).

**Writes to Supabase**:
- `products` table: upsert on `product_url`, 50 rows per batch.
- `reviews` table: insert for each product's embedded review array (if present).

**Supabase auth**: `SUPABASE_SERVICE_ROLE_KEY`.

---

### `src/import-attributes.ts`

**Command**: `pnpm import:attributes`

**Flags**: None documented.

**Reads**: Crawled product data (supplementary attribute enrichment).

**Writes to Supabase**: Attribute fields on existing `products` rows.

**Notes**: Supplementary script. Use case is re-enriching existing records without re-crawling.

---

### `src/import-brand-nodes.ts`

**Command**: `pnpm import:brand-nodes`

**Flags**: None.

**Reads**: `data/Fashion_genome_*.xlsx` — glob match, all matching files are processed.

**Writes to Supabase**: `brand_nodes` table (upsert).

**Notes**: The XLSX file is not generated by this repo. It is a manually maintained fashion taxonomy file. Ensure the file is present in `data/` before running.

## Stage 3: Analyze

### `src/analyze-products.ts`

**Command**: `pnpm analyze:products`

**Flags**: None.

**Reads**: `products` rows from Supabase that do not yet have a corresponding `product_analyses` entry. Selects `imageUrl` for vision inference.

**Writes to Supabase**: `product_analyses` table.

**Rate limiting**: Token bucket — 1500ms interval, 3 tokens per batch. This controls the call rate to the LiteLLM proxy to stay within quota.

**External call**: LiteLLM proxy at `LITELLM_API_BASE` using the `openai` SDK. Model: `nova-lite` (vision).

**Prompt**: `src/configs/analyze-prompt.ts`.

## Dev / Diagnostic Utilities

### `src/probe-reviews.ts`

**Command**: `pnpm probe:reviews`

**Purpose**: Diagnostic. Visits a site's product pages and inspects the review section structure without writing anything. Used when adding or debugging a review parser.

**Reads**: SiteConfig from `src/configs/platforms.ts`.

**Writes**: Console output only. No file or Supabase writes.

---

### `src/test-detail-crawl.ts`

**Command**: `pnpm test:detail`

**Purpose**: Dev utility. Runs the Cafe24 detail page crawl on a single product URL and prints the result. Used to validate `crawlDetails` behavior for a specific site.

**Reads**: SiteConfig, detail parser (if registered).

**Writes**: Console output only.

---

### `src/test-parser.ts`

**Command**: `pnpm test:parser`

**Purpose**: Dev utility. Tests a registered parser against a live page and prints raw output. Used when writing or debugging a new `detail/` or `review/` parser.

**Reads**: SiteConfig, parser module.

**Writes**: Console output only.
